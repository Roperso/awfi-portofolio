---

## ✨ Features

- **🌌 Interactive 3D Hero Section**: Real-time 3D sculptural canvas object powered by Three.js / React Three Fiber with custom parallax starfield effects.
- **🧩 Magic Bento Grid**: Interactive capability cards built with GSAP spotlight cursor tracking, particle starbursts, magnetic hover, and 3D tilt effects.
- **⚡ Dynamic Tech Stack Marquee**: Dual-direction infinite scrolling ticker showcasing core development tools and languages with official brand logos & custom brand-color hover transitions.
- **📁 Projects Showcase with Category Filtering**: Filterable portfolio grid (*All*, *Data Science*, *Game Development*, *Computer Vision*, *UI/UX & Design*) with direct **Live Demo** and **GitHub Repository** links.
- **📜 Verified Certificates Lightbox**: Interactive credentials showcase with full-screen image inspection lightbox.
- **📱 Fully Responsive & Optimized**: Flawless layout adaptivity across mobile, tablet, and ultra-wide desktop viewports.

## ⚙️ Getting Started

### Prerequisites

Ensure you have **Node.js** (v18 or higher) and **npm** installed on your machine.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Roperso/awfi-portofolio.git
   cd awfi-portofolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
